# ScannerKit

Private binary Swift Package distribution for ScannerKit. Customers add the
package URL from the private GitHub repository and select the single
`ScannerKit` library product. ScannerKit, IDScanner, and DocumentScannerKit
are included internally; implementation source is not distributed.

```swift
import ScannerKit
```

The package requires iOS 16 or newer. Configure and activate a valid license
before presenting the scanner.
